# Ubuntu Agent Installation Images

This directory contains the screenshots referenced in **07-ubuntu-agent.md**.

- ubuntu-agent-repository.png

## Description

These screenshots document the complete installation, configuration, and verification of the Wazuh Agent on an Ubuntu endpoint.

The images demonstrate:

- Adding the official Wazuh APT repository and verifying package availability.
- Configuring the Wazuh Agent to communicate with the Wazuh Manager.
- Starting and verifying the Wazuh Agent service on Ubuntu.
- Confirming successful agent registration and connectivity from the Wazuh Manager.

These screenshots correspond to the deployment process described in **07-ubuntu-agent.md**.
