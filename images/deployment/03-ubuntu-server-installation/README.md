# Ubuntu Server Installation Images

This directory contains the screenshots referenced in **03-ubuntu-server-installation.md**.

## Images

- login-screen.png
- user-login.png
- hostname-ip.png
- system-update.png

## Description

These screenshots document the successful installation and initial configuration of the Ubuntu Server virtual machine before deploying the Wazuh platform.

The images demonstrate:

- Ubuntu login screen after the first successful boot.
- User authentication.
- Verification of the assigned IP address.
- Updating the operating system before installing Wazuh.

These screenshots correspond to the deployment process described in **03-ubuntu-server-installation.md**.
