## Description

These screenshots document the complete installation and registration of the Wazuh Agent on a Windows endpoint.

The images demonstrate:

- Downloading the Wazuh Windows Agent installer.
- Installing the Wazuh Agent on Windows.
- Registering the Windows agent with the Wazuh Manager using the authentication key.
- Starting and verifying the Wazuh Agent service on Windows.
- Confirming successful agent registration from the Wazuh Manager using the `agent_control -l` command.

These screenshots correspond to the deployment process described in **06-windows-agent.md**.
