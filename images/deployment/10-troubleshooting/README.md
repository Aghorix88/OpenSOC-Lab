# Troubleshooting Images

This directory contains the screenshots referenced in `10-troubleshooting.md`.

## Images

- `dashboard-not-ready.png` — Wazuh Dashboard displaying the "server is not ready yet" message.
- `indexer-oom-kill.png` — Wazuh Indexer service terminated due to an Out of Memory (OOM) condition.
- `authentication-error.png` — Authentication failure caused by an invalid or mismatched agent key.
- `duplicate-agent-error.png` — Duplicate agent registration detected by the Wazuh Manager.
- `windows-permission-error.png` — Windows permission error encountered while editing the Wazuh agent configuration.
- `dashboard-recovered.png` — Wazuh Dashboard successfully restored after troubleshooting and fixes.
